Place these JAR files in this folder:

1. JavaFX SDK — download from https://gluonhq.com/products/javafx/
   Extract and place the entire javafx-sdk/ folder here.
   The .classpath already references the JARs inside lib/javafx-sdk/lib/

2. MySQL Connector/J — download from https://dev.mysql.com/downloads/connector/j/
   Rename the jar to: mysql-connector-j-8.x.jar
   Place it directly in this lib/ folder.
